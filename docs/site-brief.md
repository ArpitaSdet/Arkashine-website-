## Positioning (from report)
Not "AI soil testing machine" — **soil-intelligence infrastructure for organisations serving farmers**.
AI is an enabling layer; the moat is **science + patents + field deployment + actionable advice + economics**.

Target line: *We enable FPOs, corporates, CSR programmes and agricultural organisations to deploy rapid,
data-driven soil testing at the farmer's doorstep — with patented technology, digital records,
actionable recommendations and an economically scalable operating model.*

Suggested hero: **Portable Soil Intelligence for On-Farm Testing at Scale** — AI-enabled soil testing and crop
advisory for FPOs, agri-enterprises, CSR programmes and farmer-service networks.
CTAs: **Book a Live Demo** (primary) · **Download Technical Brochure**.

Buyers: FPOs, corporate agriculture, CSR programmes, NGOs, agri-input companies, government / KVKs,
soil-testing entrepreneurs (SHGs, village-level service providers).

## Product: SOILENZ 2.0 (from manual)
- Smart soil testing machine + **Soil Partner** Android app over Bluetooth; built-in receipt printer
- Kit: SOILENZ 2.0 unit, Soil Setter, pH/EC bottle
- **Parameters:** pH, EC, temperature + 12-parameter panel — Organic Carbon, N, P, K, Ca, Mg, S, Fe, Mn, Cu, Zn, B
- Results colour-coded High / Normal / Low, overall soil-health score, charts, fertiliser recommendations,
  AI insights, printable / downloadable advisory report
- Farmer registry in app: name, phone, Aadhaar, state/district/village, GPS, land area, primary crop,
  season (Kharif / Rabi / Zaid); status pipeline Registered → Sample collected → Testing done → Report delivered;
  payment history
- Workflow:
  1. pH/EC: 5 g soil + 50 ml extractant → 60 s EC mixing → 60 s pH mixing → result
  2. 12-parameter: 5 g soil + 40 ml extractant → mix 2 min → pour into device → filter ~5 min →
     remove filter paper, settle ~1 min → sensor reading → results
- Price: ₹1,20,000 (+GST) per unit (report)

Manual screenshots use demo values (e.g. pH 12.68) — never publish them as real results.
